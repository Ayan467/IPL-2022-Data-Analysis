# IPL-2022-Data-Analysis
IPL Data Analysis

A data analysis and visualization project based on IPL 2022 match data using Python.

📌 Project Overview

This project analyzes historical IPL 2022 match data to identify useful insights about matches, toss decisions, match outcomes, and player performances.

The project focuses on data cleaning, data manipulation, exploratory data analysis, and visualization using Python libraries.

🛠️ Technologies & Libraries
Python
NumPy
Pandas
Matplotlib
Seaborn
Jupyter Notebook
📂 Dataset

The project uses an IPL.csv dataset containing IPL 2022 match information, including:

Match venue
Toss winner and toss decision
Match winner
Match result
Innings scores
Player of the Match
Match-related statistics
🔍 Analysis Performed
1. Data Loading & Inspection

Loaded the IPL dataset using Pandas and explored its structure using:

head()
info()
describe()
DataFrame columns and basic statistics
2. Toss Decision Analysis

Analyzed whether teams preferred to:

Bat first
Field first

Visualized the distribution using Seaborn count plots.

3. Match Outcome Analysis

Analyzed how matches were won, including:

Won by runs
Won by wickets

Visualizations were created to understand the distribution of different match outcomes.

4. Player Performance Analysis

Identified players who received the most Player of the Match awards during the season.

📊 Visualizations

The project includes visualizations created using Matplotlib and Seaborn to understand:

Toss decisions
Match results
Player of the Match distribution
Other IPL match trends
